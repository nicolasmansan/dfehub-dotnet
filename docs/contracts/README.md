# Matrizes de contrato

Cada PR de API deve substituir o marcador pendente de seu arquivo por uma linha para
cada operação oficial.

| Operação | Fonte | Versão/auth | Método e rota | Request | Response | Status | Fixture | Testes | Observações |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Exemplo | URL oficial | V2/Bearer | `POST /2/exemplo` | `ExampleRequest` | `ExampleResponse` | Pendente | Pendente | Pendente | Remover esta linha |

Uma API só está completa quando todos os endpoints documentados na data de
congelamento estão implementados ou possuem exclusão justificada em ADR.
